## 1. Introduction

This Test Plan covers manual test cases for each functional requirement (FR) defined in the Software Requirements Specification (SRS) for the College Event Management System. Each FR includes Unit (UT), Integration (IT), and System (ST) level test cases, following the naming convention <FR_ID>_<Type>_<Sequence> (e.g., FR01_UT_01).

The 'Actual Result' and 'Test Result' columns are intentionally left blank and are to be populated during manual test execution, per the project's Test Plan instructions.
