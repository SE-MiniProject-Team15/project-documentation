# Test Case Document

## College Event Management System

## Team 15

Tech Stack: JavaScript (MERN Stack)

## 1. Introduction

This Test Case Document is the companion to the Software Test Plan (STP) for the College Event Management System. It covers manual test cases for each functional requirement (FR), and the non-functional (NFR) and security (SEC) requirements, defined in SRS v1.2, and is aligned with SAD v1.0 (API endpoints in §4.4, error handling in §4.5). Each FR includes Unit (UT), Integration (IT), and System (ST) level test cases, following the naming convention `<FR_ID>_<Type>_<Sequence>` (e.g., `FR01_UT_01`). Non-functional cases follow `NFR_<AREA>_<Sequence>` (e.g., `NFR_PERF_01`) and are listed separately in Section 4.

The 'Actual Result' and 'Test Result' columns are intentionally left blank and are to be populated during manual test execution, per the project's test plan instructions.
